CareDesk · Fase 2 · Puesta en marcha

Guía para crear el proyecto en Supabase

Sigue estos pasos (15–20 min). Al final me pasas dos claves y yo conecto el login, el registro, la demo y las licencias a tu base de datos. No necesitas saber programar: es todo clicar y pegar.

Parte A · Crear el proyecto

1

Crea tu cuenta

Entra en supabase.com y pulsa Start your project. Puedes registrarte con tu email o con GitHub. Es gratis.

2

Crea un proyecto nuevo

New project. Ponle nombre caredesk. Elige una Database Password segura y apúntala (la necesitarás si algún día entras a la base a mano).

Region: elige Europe (Frankfurt) — cercanía y datos en la UE (mejor para el RGPD).

Pulsa Create new project y espera 1–2 min a que se monte.

Parte B · Crear las tablas

3

Abre el editor SQL

En el menú izquierdo, entra en SQL Editor → New query.

4

Pega el esquema y ejecútalo

Abre el archivo que te paso, caredesk_schema.sql, selecciona todo y cópialo. Pégalo en el editor SQL y pulsa Run (o Ctrl+Enter).

Si todo va bien verás “Success. No rows returned”. Eso crea las tablas de cuentas, licencias, alumnos y el control de la demo.

Parte C · Ajustes de acceso (Auth)

5

Facilita las pruebas de hoy

Ve a Authentication → Providers → Email y asegúrate de que Email está activado.

Para probar rápido hoy, en Authentication → Sign In / Providers (o Email) desactiva “Confirm email” temporalmente. Así las cuentas de prueba entran sin tener que confirmar el correo. Antes de vender, lo volvemos a activar.

Parte D · Pásame dos claves

6

Copia la URL y la anon key

Ve a Project Settings (el engranaje) → API. Copia estos dos valores y me los pegas en el chat:

Project URL → https://xxxxxxxx.supabase.co
anon public → eyJhbGciOi... (una clave larga)
Tranquilo: la anon key es pública por diseño (va en la web); la seguridad la ponen las reglas RLS que acabas de crear. NUNCA me pases la service_role ni la Database Password.

Y ya está por tu parte. Cuando me pases esas dos claves:

Conecto el login único, el registro de profesor, la demo de 3 días y las licencias a tu Supabase y te doy una versión para publicar y probar. Después ajustamos el alta de alumnos por email (suele necesitar una o dos vueltas contra tu proyecto real) y lo dejamos redondo.

Qué queda montado con esto

Cuentas reales de profesor y alumno, licencia por curso, demo de 3 días con antifraude (un email no la repite), tope de 30 alumnos, y el acceso del alumno solo si su profesor lo ha invitado — todo con la seguridad de las reglas RLS. El diseño y las pantallas serán las del prototipo que ya validaste.
